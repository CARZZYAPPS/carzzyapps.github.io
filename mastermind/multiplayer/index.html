How to Play (Multiplayer Mode)

In this multiplayer duel, players are assigned one of two roles:

🛠️ Codemaker: Set a secret 4-color code for the opponent.
🔍 Codebreaker: Guess the secret code in 10 or fewer turns.

Deciphering Clues

Feedback clue pegs automatically show how close the guess is:

⚫   Black: Correct color in the correct spot.
⚪   White: Correct color, but in the wrong spot.
